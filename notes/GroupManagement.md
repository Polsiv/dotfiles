
# addgroup
- `addgroup <group_name>`

# delgroup
- `delgroup <group_name>`

# groupmod
- `groupmod -n <new_group_name> <group_name>`

# gpasswd
- `gpasswd -a <username> <group_name>`: adds new user to group
- `gpasswd <group_name>`: add new pass for group

# groups
- `groups <username>`: list the groups of the username
